# 🔳 Gerador de QR Code

Aplicação web simples e intuitiva para geração de QR Codes a partir de textos ou URLs, com pré-visualização em tempo real e opção de download da imagem.

## 🚀 Funcionalidades

- Detecção automática de texto ou URL
- Geração instantânea de QR Code
- Pré-visualização em tempo real
- Download do QR Code em formato PNG
- Interface moderna e responsiva
- Funciona 100% no navegador (sem back-end)

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Biblioteca QRCode.js
- GitHub Pages (deploy)

## 🧠 Como funciona

1. O usuário digita um texto ou URL
2. O sistema identifica automaticamente o tipo de conteúdo
3. O QR Code é gerado em tempo real no navegador
4. O usuário pode baixar o QR Code em PNG
